## Official API basis

[CharacterBody3D](https://docs.godotengine.org/en/stable/classes/class_characterbody3d.html) documents script-owned move_and_slide, collision recovery margin, floor/wall platform masks and leave-velocity behavior. Those settings motivate explicit no-carry configuration; they are not evidence of this candidate's outcome.
