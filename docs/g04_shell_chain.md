Normal main launch retains G03 default and adds **G04 R32 Chain** and **G04 R33 Chain**. Each separate declared review has five ordinary available people, R02 initially selected and only raw depot stock: R32 gets 140 M01 + 200 M03; R33 gets 70 M01 + 200 M03. The same existing selection, stock-target stepper, reporting, hauling, time and confirmation controls are used. The additional M06 to input button requests real output-to-input hauling; it does not move or grant goods itself.

Select R27, Stock target and minimum 20; assign Hauling 1 and advance elapsed rear time until twenty actual completions deposit twenty M06. Target 20 prevents an unwanted 21st consumed batch. Twenty R27 receipts consume exactly 40 M01 + 200 M03, at 40 operator-work each. Select the shell recipe and set minimum 1: it still reports missing twenty local M06, while the finished explosives remain in output. Request M06 to input; actual pickup/carry/drop transfers each one-unit output. Domain cases explicitly stop at the final carried unit: nineteen local plus one carried cannot consume anything. Ledger portion origin IDs trace all twenty deposited/consumed units to their R27 output identities.

After actual deposit, a shell batch consumes its full metal/explosive receipt once and promises 120 or 50 kg. Partial work can be retained across a declined recipe change and blocked access. Complete remaining work to deposit ten E25 or a hundred E26. Exact combined chain consumption is 140 M01/200 M03/20 M06 for R32, or 70 M01/200 M03/20 M06 for R33, with zero free initial explosives or duplicate shell outputs. Production and hauling use elapsed event boundaries and exclusive people, not fixture resets or teleportation. No later loading, delivery or firing is inferred.
