# G05 rear construction

The connected rear owns one construction service on its existing event clock. A placed site reserves a bounded physical footprint and entrance. Its M11 is delivered by the existing hauling jobs into a ledger place; a maximum of four ordinary builders per active site earn the catalogue work seconds. First positive work consumes the floor half of required M11, and completion consumes the remainder. Cancelling before work returns all delivered M11; after work starts, only the unconsumed half returns by physical hauling.

The service copies the GDD §8.1 F02–F07 and F09–F13 build costs, work and capacities. F01 and F08 stay fixed. Each completed copy owns its storage, staffing positions and production or service activity. Extra F02 berths extend the common supplier waiting pool by one physical berth each; extra F06 sites add twelve seats and two instructor positions; extra F07 berths select the existing dispatch manifest lifecycle; extra F10 bays use the existing heavy order, G07 driving and G12 two-loader E13 collection; extra F11 sites add four actual parking places. Each F12 office has four positions for the same actual builders who transfer to and from active sites. An office's requested staff includes its people currently serving at sites, so it does not recruit duplicate bodies; a staffed second F12 can support a second concurrent site. No additional mission, convoy or global inventory service is introduced.

Placement checks building overlap, map bounds, entrance and walking access, protected existing routes, and an eight-metre vehicle connection for new F07/F10/F11 sites. The vehicle path is a local visibility graph around the current facility footprints. A copy F10 hull leaves through its own entrance; dispatch from a copy F07 uses that berth's route to the rear exit. These are bounded rear-base geometry decisions, not world navigation.

Dismantling refuses protected starters, live batches, occupied or reserved outputs, committed supplier berths, manifests, seats and parking. The starting F02 receiving admission, F12 builder office and F13 M11 production each report their protected recovery function when dismantling is requested. Existing goods are hauled away before twenty builder work seconds. The site then yields floor half of its build M11 as a physical salvage stack, which must be hauled to the depot. The footprint remains reserved until that stack clears.
