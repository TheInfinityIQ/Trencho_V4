# Bounded autonomous mounted fire

`VehicleExecution` belongs to the scene-owned `SquadExecution`. Its `next_boundary()`, `settle()` and detached `snapshot()` add mounted action deadlines to the existing rear clock, independently of the one-second infantry decision interval. It handles only attached blue T03/T04 elements. Hull deployment, operation scoring, HQ assault and tank execution remain separate assignments.

The helper reads targets only from current contacts actually delivered to the element's attached platoon or company, through `Orders.contact`. It neither scans hostile entities nor grants observers, crew, ammunition or fuel. A positive vehicle readiness score and the existing explicit Fire capability are required. Hulls committed to troop movement or forward supply, and towing hulls, wait. Empty racks generate a command Low Supply report; other missing capability is reported upward. Repeated unchanged deficits do not flood reports.

The existing VehicleCombat service remains the authority for operators, aim, actual target validity, range, terrain observation/firing line, friendly line/blast, rack reservations, consumption, cadence, reload and impact. A previously unused turret starts from actual hull bearing; an existing mount retains its state. Stable targets do not restart aim. An unfinished turn completes before reacquisition: the service stores its desired angle immediately, so treating it as an already reached angle could otherwise shorten a turn for a moving contact. Upcoming aim, shot and reload deadlines enter the clock only when strictly in the future, preventing expired-boundary loops. An acquired usable target takes precedence so a nearer refused contact does not continually reset aim.

Target class is reported information. MG fire skips armoured T04/T05 hulls; the T04 cannon skips T05 because it cannot penetrate front/side armour and this contribution has no observed-facing flank plan. Neither mount attacks HQ markers. Ordinary valid exposed targets and unarmoured hulls remain subject to all service guards. This conservative selection does not implement the full tactical vehicle AI.

The focused regression obtains actual observations and hierarchy delivery, then verifies an empty T04 cannot shoot, a timed physical ForwardSupply rack issue enables autonomous E26 release, T03 uses actual E02 at quarter-second cadence and takes the real six-second reload, stale/unreported contacts cannot fire, and terrain/friendly line/blast/armour/crew/reserved-rack refusals hold. Coarse/fractional clock partitions preserve shot times, stores and damage. A non-default opposite hull bearing verifies actual turn time. Tests never call aim, fire or reload directly.

The existing military audit reports an unqualified retained crew station after a gunner dies; the loss-of-gunner test checks refusal after the actual injury, while clean audits cover the preceding safety paths and the other live-crew cases. Crew casualty cleanup is not modified here. Scene input and deployed opening experience remain lead/designer integration checks.
