# Route interval sweep

The connected Farmland opening profile measured TerrainWorld.route at 36.128 seconds total / 28.271 seconds self across 104 calls; the first three troop admissions took 35.732 seconds. The old aggregation scanned every occupied-cell interval for every cut span.

Route admission, continuous footprint coverage, support/obstacle/load checks, height-edge rejection and cut generation remain in their existing owner. Aggregation sorts interval starts once, advances a cursor at each retained span midpoint and removes expired intervals. It evaluates only active footprint cells, in original cell order. This preserves exact cut positions, EPS span omission, minimum speed factor/cap, maximum slope/fuel, ordered surfaces, per-part values and accumulation order. It does not merge spans, approximate terrain, cache mutable world results or change physical distances.

`game/terrain/tests/route_sweep_regression.gd` retains the previous aggregation as a test-only oracle. It compares complete dictionaries exactly over catalogue/variant lanes, deterministic mixed rotated lanes, height failures, synthetic nested/coincident/sub-EPS intervals and long authored Farmland lanes in both directions plus a diagonal. Timings are printed as evidence; no machine-dependent speed threshold gates CI. The check manifest includes this regression.

Local first-run Godot 4.7.2 measurements: a 1,650-metre authored axis lane took 1.596 seconds legacy / 0.406 seconds sweep (reverse: 1.692 / 0.408); a 222-metre authored diagonal took 0.299 / 0.165 seconds. These are complete route-call timings, including unchanged footprint and support admission. Integrated opening profiling and playable performance acceptance remain with the lead and designer.

A bounded `--debug --profiling` run with an additional 738-metre authored diagonal measured 144 calls to each aggregation: legacy 6.798 seconds total / 6.709 self; sweep 1.069 total / 0.978 self (about 6.4 times less total aggregation time). The diagonal itself took 3.210 seconds legacy / 1.157 sweep, with all 5,701 parts identical. All 202 equivalence checks passed. Profile output is local at `.artifacts/route-sweep-profile.txt`. Profiling overhead changes absolute timings; the compared calls run in the same process. Active work depends on simultaneous footprint overlap rather than the entire route's occupied-cell count; the original geometric scan of a diagonal lane's bounding rectangle is unchanged.
