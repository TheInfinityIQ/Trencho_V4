## Two fixed owners and one clock

`fixed_production.gd` extracts the accepted R01 lifecycle, guards, fractional endpoint tolerance and A/C query for exactly two declared activities. Thin R01/F04 and R02/F05 scripts select fixed specifications on construction; there is no runtime recipe switch or new all-recipe queue. Both then settle against the same ledger and output-space accounting. A person has one actual duty and location, so cannot operate both facilities or haul simultaneously.
